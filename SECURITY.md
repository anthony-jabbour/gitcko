# Security policy

## Reporting a vulnerability

**Don't open a public issue, pull request or discussion for a vulnerability.**

Report it privately through **[GitHub private vulnerability reporting](https://github.com/anthony-jabbour/gitcko/security/advisories/new)** on this repository.

Please include what is affected (version or commit), how to reproduce it, and what an attacker could do with it.

## What to expect

| Step | Target |
|---|---|
| Acknowledgement | within 2 business days |
| Initial assessment | within 7 days |
| Fix or mitigation, and coordinated disclosure | within 90 days, sooner if the issue is being exploited |

You'll be credited in the GitHub Security Advisory unless you'd rather not be.

## Scope

- This repository and the code in it.
- Released binaries, packages and container images built from it.
- Gitcko Cloud, once it exists.

Out of scope: testing against other people's data or accounts, denial-of-service attacks, and social engineering.

## Supported versions

Gitcko is pre-alpha and has no releases yet. Once releases start, security fixes go to the latest release.
